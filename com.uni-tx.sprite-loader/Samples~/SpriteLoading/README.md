# Sprite Loading

Loading a formatted addressable sprite key into an Image and releasing it cleanly.

Part of [UniTx Sprite Loader](https://github.com/uni-tx/kit/blob/main/com.uni-tx.sprite-loader/README.md) v1.1.0.

## Using it

1. Import from **Package Manager ▸ UniTx Sprite Loader ▸ Samples ▸ Sprite Loading**.
2. Open the imported folder under `Assets/Samples/UniTx Sprite Loader/1.1.0/Sprite Loading`.
3. Read the source — every non-obvious line carries a comment explaining *why*, not just
   what.
4. Follow the `<remarks>` on the main type for scene setup, if any is needed.

Samples live under `Samples~`, which Unity excludes from compilation until you import
them, so they add nothing to your build unless you ask for them.
