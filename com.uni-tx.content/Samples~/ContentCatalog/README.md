# Content Catalog

Registering data types, loading a JSON catalog by label, and querying it by id and by type.

Part of [UniTx Content](https://github.com/uni-tx/kit/blob/main/com.uni-tx.content/README.md) v1.1.0.

## Using it

1. Import from **Package Manager ▸ UniTx Content ▸ Samples ▸ Content Catalog**.
2. Open the imported folder under `Assets/Samples/UniTx Content/1.1.0/Content Catalog`.
3. Read the source — every non-obvious line carries a comment explaining *why*, not just
   what.
4. Follow the `<remarks>` on the main type for scene setup, if any is needed.

Samples live under `Samples~`, which Unity excludes from compilation until you import
them, so they add nothing to your build unless you ask for them.
