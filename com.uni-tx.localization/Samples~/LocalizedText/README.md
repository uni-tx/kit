# Localized Text

Switching locale at runtime and binding a localized string table entry to a label.

Part of [UniTx Localization](https://github.com/uni-tx/kit/blob/main/com.uni-tx.localization/README.md) v1.1.0.

## Using it

1. Import from **Package Manager ▸ UniTx Localization ▸ Samples ▸ Localized Text**.
2. Open the imported folder under `Assets/Samples/UniTx Localization/1.1.0/Localized Text`.
3. Read the source — every non-obvious line carries a comment explaining *why*, not just
   what.
4. Follow the `<remarks>` on the main type for scene setup, if any is needed.

Samples live under `Samples~`, which Unity excludes from compilation until you import
them, so they add nothing to your build unless you ask for them.
