# Event Bus Basics

Publishing and subscribing struct events, priority ordering and safe unsubscribe during dispatch.

Part of [UniTx Events](https://github.com/uni-tx/kit/blob/main/com.uni-tx.events/README.md) v1.1.0.

## Using it

1. Import from **Package Manager ▸ UniTx Events ▸ Samples ▸ Event Bus Basics**.
2. Open the imported folder under `Assets/Samples/UniTx Events/1.1.0/Event Bus Basics`.
3. Read the source — every non-obvious line carries a comment explaining *why*, not just
   what.
4. Follow the `<remarks>` on the main type for scene setup, if any is needed.

Samples live under `Samples~`, which Unity excludes from compilation until you import
them, so they add nothing to your build unless you ask for them.
