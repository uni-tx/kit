# Projectile Pool

A pooled projectile with Initialize/Reset hooks, typed spawn data and automatic return.

Part of [UniTx Pooling](https://github.com/uni-tx/kit/blob/main/com.uni-tx.pooling/README.md) v1.1.0.

## Using it

1. Import from **Package Manager ▸ UniTx Pooling ▸ Samples ▸ Projectile Pool**.
2. Open the imported folder under `Assets/Samples/UniTx Pooling/1.1.0/Projectile Pool`.
3. Read the source — every non-obvious line carries a comment explaining *why*, not just
   what.
4. Follow the `<remarks>` on the main type for scene setup, if any is needed.

Samples live under `Samples~`, which Unity excludes from compilation until you import
them, so they add nothing to your build unless you ask for them.
