# Audio Playback

2D/3D/attached SFX, music with crossfade, and mixer-backed volume and mute controls.

Part of [UniTx Audio](https://github.com/uni-tx/kit/blob/main/com.uni-tx.audio/README.md) v1.1.0.

## Using it

1. Import from **Package Manager ▸ UniTx Audio ▸ Samples ▸ Audio Playback**.
2. Open the imported folder under `Assets/Samples/UniTx Audio/1.1.0/Audio Playback`.
3. Read the source — every non-obvious line carries a comment explaining *why*, not just
   what.
4. Follow the `<remarks>` on the main type for scene setup, if any is needed.

Samples live under `Samples~`, which Unity excludes from compilation until you import
them, so they add nothing to your build unless you ask for them.
