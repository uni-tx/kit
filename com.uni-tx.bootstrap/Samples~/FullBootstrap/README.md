# Full Bootstrap

A complete AppLoader scene wiring config, IoC bindings and every UniTx service.

Part of [UniTx Bootstrap](https://github.com/uni-tx/kit/blob/main/com.uni-tx.bootstrap/README.md) v1.1.0.

## Using it

1. Import from **Package Manager ▸ UniTx Bootstrap ▸ Samples ▸ Full Bootstrap**.
2. Open the imported folder under `Assets/Samples/UniTx Bootstrap/1.1.0/Full Bootstrap`.
3. Read the source — every non-obvious line carries a comment explaining *why*, not just
   what.
4. Follow the `<remarks>` on the main type for scene setup, if any is needed.

Samples live under `Samples~`, which Unity excludes from compilation until you import
them, so they add nothing to your build unless you ask for them.
