# Safe Area Layout

Keeping UI clear of notches, punch-holes and the home indicator, including landscape balancing.

Part of [UniTx Widgets](https://github.com/uni-tx/kit/blob/main/com.uni-tx.widgets/README.md) v1.1.0.

## Using it

1. Import from **Package Manager ▸ UniTx Widgets ▸ Samples ▸ Safe Area Layout**.
2. Open the imported folder under `Assets/Samples/UniTx Widgets/1.1.0/Safe Area Layout`.
3. Read the source — every non-obvious line carries a comment explaining *why*, not just
   what.
4. Follow the `<remarks>` on the main type for scene setup, if any is needed.

Samples live under `Samples~`, which Unity excludes from compilation until you import
them, so they add nothing to your build unless you ask for them.
