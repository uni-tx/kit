# App Bootstrap

An AppLoader driving ordered loading steps, with a custom step of your own.

Part of [UniTx Core](https://github.com/uni-tx/kit/blob/main/com.uni-tx.core/README.md) v1.1.0.

## Using it

1. Import from **Package Manager ▸ UniTx Core ▸ Samples ▸ App Bootstrap**.
2. Open the imported folder under `Assets/Samples/UniTx Core/1.1.0/App Bootstrap`.
3. Read the source — every non-obvious line carries a comment explaining *why*, not just
   what.
4. Follow the `<remarks>` on the main type for scene setup, if any is needed.

Samples live under `Samples~`, which Unity excludes from compilation until you import
them, so they add nothing to your build unless you ask for them.
