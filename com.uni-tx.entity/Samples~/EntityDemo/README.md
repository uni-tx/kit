# Entity Demo

An entity backed by content data and a save file, wired through the entity service.

Part of [UniTx Entity](https://github.com/uni-tx/kit/blob/main/com.uni-tx.entity/README.md) v1.1.0.

## Using it

1. Import from **Package Manager ▸ UniTx Entity ▸ Samples ▸ Entity Demo**.
2. Open the imported folder under `Assets/Samples/UniTx Entity/1.1.0/Entity Demo`.
3. Read the source — every non-obvious line carries a comment explaining *why*, not just
   what.
4. Follow the `<remarks>` on the main type for scene setup, if any is needed.

Samples live under `Samples~`, which Unity excludes from compilation until you import
them, so they add nothing to your build unless you ask for them.
